After four billion years of wishes, howls, and 2 a.m. promises that everyone will change, the Moon finally files its report: it is still just a rock, and humanity is still texting its ex — a single wry comeback from a very old, very tired celestial neighbour who has heard it all before and is not impressed.

## How it works

`main.ts` writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), using Node's standard library only and no network.
